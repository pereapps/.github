# Pere Apps

### Built to Fly. Free Forever.

**Thoughtfully crafted apps. Free forever.**

Pere Apps is an independent software initiative dedicated to creating fast, lightweight, and beautifully designed applications.

Inspired by the **Peregrine Falcon**, a symbol of speed, precision, and freedom, we believe great software should be powerful, intuitive, and accessible to everyone.

Our mission is simple: build useful software that people genuinely enjoy using — without subscriptions, advertisements, or unnecessary limitations.

---

## Our Apps

### PereMD — Markdown, Fast & Simple

A lightweight, high-performance Markdown reader built with Rust.

Designed for speed, simplicity, and extensibility, PereMD combines a remarkably small installer with a clean interface and powerful capabilities.

**Highlights**
- Built with Rust for performance and efficiency
- Lightweight installer and fast startup
- Raw, Preview, and Dual viewing modes
- Extensible plugin architecture
- Clean, distraction-free reading experience

[Explore PereMD](https://github.com/pereapps/PereMD)

### PereTerm — Connect Without Limits

A fast, modern application for SSH and remote desktop connections.

PereTerm aims to make remote access simple, efficient, and enjoyable, bringing essential tools together in a thoughtfully designed experience.

**Highlights**
- SSH and remote desktop connectivity
- Streamlined connection management
- Modern, intuitive interface
- Designed with cross-platform support in mind

[Explore PereTerm](https://github.com/pereapps/PereTerm)
